Notes App Architecture

React 19, TypeScript, Vite, JSON Server 기반 노트 앱의 컴포넌트 의존성, 상태 소유권, API 호출 흐름을 Mermaid로 시각화한 문서입니다.

App은 화면 조합과 selectedNoteId, isCreating 같은 로컬 UI 상태만 소유합니다.

노트 서버 상태와 CRUD 액션은 NotesContext가 소유하며, 컴포넌트는 useNotes()로 접근합니다.

API 호출 시퀀스

sequenceDiagram
  participant User as 사용자
  participant UI as NoteEditor / NoteList
  participant Context as NotesContext
  participant API as src/api/notes.ts
  participant Server as JSON Server

  User->>UI: 생성, 수정, 삭제 액션
  UI->>Context: createNote / updateNote / deleteNote
  Context->>API: createNote / updateNote / deleteNote
  API->>Server: POST / PATCH / DELETE /notes
  Server-->>API: 성공 응답
  API-->>Context: Note 또는 void
  Context->>Context: notes 상태 갱신
  Context-->>UI: 최신 상태 렌더링

  Note over UI,Context: alert는 사용하지 않고 오류는 console.error로 기록
