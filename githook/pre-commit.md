# Pre-commit 지침
커밋 전에는 staged 파일만 기준으로 변경 내용을 확인한다.
검증자는 파일을 수정하지 않고 read-only로 판정만 한다.

## 확인 항목
- staged 변경이 요청 범위에 한정되어 있는지 확인한다.
- AGENTS.md의 프로젝트 구조, 코드 컨벤션, 상태 관리/API 호출 패턴을 어기지 않았는지 확인한다.
- AGENTS.md의 린트, 포맷, TypeScript 규칙에 맞지 않는 변경이 없는지 확인한다.
- `alert`, 직접 `fetch`, 잘못된 CRUD 네이밍, 새 default export처럼 금지된 패턴이 추가되지 않았는지 확인한다.
- import 순서, 파일 위치, 공용 타입 위치가 AGENTS.md 기준과 맞는지 확인한다.

## 검증
- 코드 변경은 `npm run build`를 우선 실행한다.
- 린트/포맷 영향이 있으면 `npm run lint`를 실행한다.
- 동작 변경이나 테스트 영향이 있으면 `npm test`를 실행한다.

## 중단 조건
- staged 변경이 AGENTS.md 규칙과 충돌하면 커밋을 중단한다.
- 필요한 검증 명령이 실패하면 커밋을 중단한다.
- 사용자 요청과 AGENTS.md가 충돌하면 커밋을 진행하지 말고 확인을 요청한다.

## 반환
- 통과하면 `code: 0`을 반환한다.
- 실패하면 `code: 1`과 실패 이유, 관련 파일 또는 규칙을 반환한다.
