# Security Review

## 목적

리팩토링 완료 후 커밋 전에 타입 오류와 보안 취약점을 점검하고, 수정 필요성을 분류한다. `$ARGUMENTS`는 반드시 `<카테고리>-<이슈번호>` 형식의 이슈 식별자여야 한다. 예를 들어 `tag-1`은 `tag` 카테고리의 1번 이슈를 의미하는 단순 예시다.

## 입력 규칙

- 실행 인자는 반드시 `<카테고리>-<이슈번호>` 형식으로 전부 전달되어야 한다.
- 예: `tag-1`, `note-3`, `search-12`.
- 인자가 없거나 단순 숫자만 전달되면 어떤 카테고리의 이슈인지 알 수 없으므로 스킬을 실행하지 않는다.
- 잘못된 입력이면 점검을 시작하지 말고 `<카테고리>-<이슈번호>` 형식으로 다시 요청해 달라고 안내한다.

## 절대 제약

- 판단이 필요한 항목은 반드시 개발자 승인 후 수정한다.
- 테스트 파일을 수정하지 않는다.
- `npm audit fix --force`를 사용하지 않는다.
- 승인 전에는 파일을 수정하지 않는다.
- 승인 후에도 "즉시 수정 필요"로 분류되고 승인된 항목만 처리한다.
- 보안 위험을 낮추기 위해 필요한 최소 변경만 수행한다.

## 실행 순서

1. `$ARGUMENTS`가 `<카테고리>-<이슈번호>` 형식으로 완전히 전달되었는지 확인한다. 형식이 맞지 않으면 즉시 중단하고 인자를 작성해 달라고 요청한다.
2. `AGENTS.md`를 읽고 프로젝트별 명령어, 테스트 파일 수정 금지, Git 규칙을 확인한다.
3. 타입 오류를 수집한다.
   - `npx tsc --noEmit`을 실행한다.
   - 실패해도 바로 수정하지 말고 오류 파일, 라인, 메시지를 정리한다.
4. 보안 취약점을 수집한다.
   - `npm audit`을 실행한다.
   - 취약점 패키지, 심각도, 취약 경로, 권장 조치를 정리한다.
   - `npm audit fix --force`는 절대 실행하지 않는다.
5. 환경 변수 직접 노출 여부를 확인한다.
   - `src/` 아래에서 `process.env`, `import.meta.env`, `VITE_`, `.env` 문자열 사용을 검색한다.
   - 클라이언트 번들에 포함될 수 있는 값이 직접 표시되거나 로그로 노출되는지 확인한다.
   - Vite의 `import.meta.env.VITE_*` 설정값 사용 자체는 즉시 취약점으로 단정하지 말고 사용 맥락을 본다.
6. 수집 결과를 세 가지로 분류해 개발자에게 보고한다.
   - 즉시 수정 필요: 보안 위험, secret 노출, 빌드 실패 수준의 타입 오류, 실제 취약 dependency 경로.
   - 권장 수정: 당장 빌드나 보안을 깨지는 않지만 코드 품질, 유지보수성, 방어적 검증을 저하시키는 항목.
   - 무시 가능: false positive, 개발 도구 전용 취약점, 의도된 공개 설정값, 현재 실행 경로에 영향이 없는 항목.
7. 개발자 승인 전에는 수정하지 않는다. 승인 요청에는 "즉시 수정 필요" 항목만 수정 대상으로 명시한다.
8. 승인 후 "즉시 수정 필요" 항목만 처리한다.
   - 테스트 파일은 수정하지 않는다.
   - dependency 수정이 필요하면 lockfile 영향과 대안을 설명하고, 위험한 자동 수정은 피한다.
9. 처리 후 재스캔한다.
   - `npx tsc --noEmit` 재실행.
   - `npm audit` 재실행.
   - 환경 변수 직접 노출 검색 재실행.
10. 최종 결과를 보고한다.

- 입력 이슈 식별자.
- 최초 스캔 결과 요약.
- 승인받아 처리한 항목.
- 재스캔 결과.
- 남은 권장 수정 또는 무시 가능 항목.

## 보고 형식

수정 전에는 다음처럼 보고한다.

```text
이슈: <카테고리>-<이슈번호>

즉시 수정 필요:
- <파일/패키지>: <근거와 위험>

권장 수정:
- <파일/패키지>: <근거>

무시 가능:
- <파일/패키지>: <false positive 또는 의도된 패턴인 이유>

"즉시 수정 필요" 항목만 처리해도 될지 승인해 주세요.
```

즉시 수정 필요 항목이 없으면 수정 없이 종료하고, 재스캔이 필요하지 않다고 명시한다.
